## Verified clean (worth recording)

- **`_ddev_tree_conforms` race posture — live-verified, two facts.**
  (a) GNU `stat` does **not** dereference a symlink operand by default
  (`lrwxrwxrwx`, link's own owner) — so a swapped-in symlink owned by
  the agent user fails the owner probe and gets the full, `[ -L ]`-gated
  treatment, while a symlink owned by `user:group` *conforms* (`%A` pos
  6 is `w` on links too) and the recursive pair is **skipped** — strictly
  safer than the pre-wave code, which ran `chown -R`/`chmod -R` through
  the operand in that race. (b) The `[ -L ]`→write window grows by two
  stat syscalls — same class as the pre-image's single-gate window, no
  new dereference primitive.
- **Fail directions:** every new failure mode fails toward *more*
  scanning / *less* root writing: missing stamp, tampered stamp, missing
  `cksum`/`cat`, unwritable stamp dir (`mkdir -p || return 0`,
  `> file … || true`), stub fallbacks (`return 1` / `:;`) in update.sh
  and config.sh — live-tested matrix by the quality agent, confirmed in
  code. The docs' "anything doubtful falls back to the full scan" claim
  is literally true for every constructible failure mode.
- **Stamp injection surface:** `/etc/opencode-permissions-kit` stays
  root-owned 755 (install.sh; no perm-widening anywhere) — planting a
  symlinked `handover/` dir or stamp file requires root. Content is
  compared as one quoted whole string (`[ "$(cat f)" = … ]`), no
  parsing; root paths with `|`/spaces round-trip correctly, cross-root
  and prefix spoofs rejected (live).
- **`?????w*` glob:** byte-counted 5 `?` then `w` = group-write at %A
  position 6; live dash matrix matches exactly the group-write spellings
  (2770/2775/1777/0776/0771/0777), rejects 2750/0750/2700/0700; only
  ever called on directories; no-match ⇒ full walk.
- **`.git` prune:** can only *skip handing trees to the agent*
  (fail-safe direction); status.sh's hosts scan stays report-only.
  Missed-project risk inside `.git/` is unreachable via ddev's
  walk-up-from-cwd resolution.
- **`set -eu` interactions:** all new calls sit in `if` conditions or
  unconditionally-`return 0` functions; `_ho_skip`/`_ho_announced`
  initialized; `REFRESH` argv-parsed at update.sh:386.
- **Arity/stubs:** all five `ddev_handover_stamp_write` sites pass 3
  args consistently; install.sh and config.sh carry matching fail-open
  stubs.
- **7f hermeticity:** `OPK_INSTALL_CONF` stubbed suite-wide;
  `DDEV_DEV_OWNED=true .` persistence confined to its single `sh -c`
  child; the rev-tamper block is gated by a loud stamp-existence check,
  so it cannot pass vacuously on a missing stamp.
- **Line length / conventions:** no shipped-code line of the wave
  exceeds 120 (ratchet green); variable namespaces `dhv_`/`dhw_`/`_dtc_`
  unique in the file; `DDEV_HANDOVER_STAMP_REV` carries its bump
  instruction at the definition and in the design record §2.
- **e2e baselines held** on the wave: 272/0 + 47/0 + 70/0, zero skips.
