## Verified clean (worth recording — both agents, main-agent confirmed)

- **The phase wrap is verbatim** (insertions only at the four boundaries;
  phase tails return 0; plain-statement main calls) — set -e equivalence
  holds for install.sh itself.
- **sudoers pipeline integrity**: charset gate → render → visudo on the
  RENDERED file → only then mkdir/cp/chmod 440 → link → legacy rm; sed
  injection via DEFAULT_USER impossible (charset excludes `/ & \` and
  newline); `ln -sf`/`rm -f` cannot follow planted links into
  root-owned dirs.
- **deploy-lib manifest**: quoted heredoc (no expansion/break-out),
  missing sources fail loud BEFORE writing the entry, explicit
  `return 0` tail; partial-deploy-on-failure is loud and was accepted in
  0.0.41d F1.
- **render + tui-plugin**: offline render preserved (0.0.39h F8: ONE
  staged_write per branch); chain gate fails CLOSED (undefined walker →
  skip); gates match the 0.0.39g S1 / 0.0.39h F2 designs.
- **secure-binary**: fail-SECURE in both directions (worst chown case →
  750 root:root, agent loses exec, nobody gains).
- **Env overrides** (SD_*/SB_*/DL_*/TR_*/SW_*/OPK_AGENT_HOME): none
  survive sudo env_reset; the kit's env_keep carries only the four
  documented vars into `sudo -u opencode` helper runs — developer-set
  test seams, not attack surface.
- **Streaming + old-kit upgrade path**: all five libs in both fetch
  lists; `kit_source` dies loud; update's fetch+re-exec+heal loop
  guarantees the libs exist before use — no old-kit hole.
- **Semantic deltas are exactly the documented three** (fail-loud
  re-assert, die-with-message sync failures, fail-loud plugin-dir chown)
  — nothing else changed behavior.
- **Tests/guards**: the kit-files equality guard cannot pass vacuously
  (emptiness guard + sorted diff + canaries); variable prefixes
  collision-free across all callers; docs/files.md/index rows match
  reality; the ratchet metric switched at all three meters, baseline
  shrink-only.
- **Temp hygiene**: every new mktemp is `_tmp_track`-registered AND
  explicitly removed on every handled path.
