## Follow-ups the implementation itself required

Two defects surfaced only through the new code and were fixed on the same
branch — recorded here so the next review knows they are expected:

- **C22 follow-up** (`759c38a`): the old grep -E class `[[:space:]]` matched
  the CR of a Windows hosts file; the exact awk comparison did not, so CRLF
  hosts entries counted as missing again (an issue-#46 regression). `gsub(/\r/)`
  restores the semantics.
- **D7 follow-up** (`1e842c8`): the e2e hook check grepped the unquoted hint;
  it now expects the quoted form.
