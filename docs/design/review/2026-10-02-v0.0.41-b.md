## Verified clean (worth recording)

- **Sourcing order:** install.sh kit_sources the helper in the prologue
  (before `do_deploy_phase` runs Step 7); config.sh sources at ~194,
  `render_sudoers` defined at ~475, called at ~571; update.sh sources
  at ~351, calls at ~640. No call precedes its definition.
- **Old-kit upgrade path:** update.sh run from an installed (pre-wave)
  library fetches the fresh tree and RE-EXECS the fetched copy — by the
  time the sudoers block runs, the running script IS current and
  `FILES_ROOT` carries the helper (`KIT_FILES` fetched it); the LIBDIR
  fallback only ever adds. No scenario runs the new sudoers block
  against an old library without the helper.
- **Removed `sudo mkdir -p "$CONFDIR"` (update.sh):** the helper mkdirs
  CONFDIR whenever the template exists; with the template missing
  (broken fetch) the later install.conf refresh dies on its
  rc-narrowed read guard BEFORE any write — the fail-safe direction is
  preserved on every path.
- **The 0.0.38 S1 contract holds:** visudo validates the RENDERED file
  before anything is deployed; the unit test asserts no CONFDIR file
  and no sudoers.d link exist after a rejection.
- **Charset gate preserved for all three callers** (it moved INTO the
  helper); config.sh/update.sh die, install.sh exit-1s with its audit
  line — abort policies unchanged.
- **List discipline:** `test-kit-files` (fetch list == KIT_FILES, files
  exist, deploy targets listed) and `test-workflows` (chmod
  inventories in all 3 workflows, run-step coverage) green — the
  registrations are complete by construction of those guards.
- **Ratchet proof by fire:** the wave's first draft shipped one
  122-char line; the ratchet caught it in `make test` and it was
  shortened (no regen) — the content-width metric works as designed.
- **Scratch hygiene:** the helper registers its mktemp with
  `_tmp_track` when the caller has one and rms explicitly on every
  handled failure path; install.sh's `cleanup()` lost only the dead
  `SUDO_TMP` guard (variable no longer set anywhere).
