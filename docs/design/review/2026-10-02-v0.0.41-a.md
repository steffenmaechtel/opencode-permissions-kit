## Verified clean (worth recording)

- **`set -e` equivalence:** the three phase calls are plain statements —
  no `||`, no condition context (any suppression context would silence
  errexit for a whole phase body). Phase tails are return-0 by
  construction: `log "container backend provisioned …"` (log is
  fail-open by design, unit-tested), the `DDEV_EXPORTED` carry-over
  `if … fi` (tee → 0 on the taken branch, 0 when untaken), and
  `sudo rm -rf … || true`. AND-OR-list exemption semantics are
  identical inside function bodies, so mid-body statements keep their
  former top-level behavior.
- **Positional hygiene:** the phases take no arguments; every
  `$1`/`$2`/`$@` in the wrapped region lives inside the seven nested
  helper definitions (grep-verified, line list in F2).
- **Control keywords:** every `break`/`continue`/`return` in the
  wrapped region sits inside a loop or function definition that moved
  with its phase — none crosses a phase boundary (all three boundary
  insertions land between complete top-level statements).
- **Wrap-bug class structurally unreachable:** 0 deleted lines — the
  install.conf heredoc terminator and every adjacent-string
  continuation are byte-identical; the 0.0.39o C1 space-loss class
  cannot re-trigger from this diff. `test-string-continuations` green.
- **Streaming bootstrap untouched:** the prologue (`STREAMED`
  detection, `fetch_kit`, `kit_source` + lib sourcings, ui fallbacks,
  `parse_args`) stays top-level ahead of the phase definitions, and
  the definitions precede the calls — `curl | sudo bash` semantics
  unchanged; the e2e suites exercise the streamed entry path.
- **No scope boundary introduced:** no `local`, no subshell around any
  phase — phases mutate and read the same globals the former top-level
  code did.
- **Order-sensitive test assertions hold:** test-ddev-migrate's
  export-before-handover line-order check and all install.sh content
  greps pass unchanged; install.sh carries no line over 120 (not in
  the ratchet baseline).
- **e2e baselines held:** 272/0 (e2e) + 47/0 (e2e-rootless), zero
