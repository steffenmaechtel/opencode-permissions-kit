## Verified clean (worth recording)

- **DEFAULT_USER provenance at all seven new call sites** — set and
  non-empty everywhere: update.sh initializes at :346, sources
  install.conf :353-355, falls back via `SUDO_USER`/`whoami` :358
  (no `set -u` crash on a hand-edited conf missing the key); config.sh
  the same pattern at :85-91; install.sh enforces charset + non-empty
  at :406-411.
- **Shape injection impossible**: the dev user is the LAST field and the
  compare is exact whole-string `[ "$(cat)" = ... ]` — `|`/newline
  values can only equal themselves; no cross-shape or cross-root spoof
  (all compared inputs are root-owned). Old 5-field stamps: write always
  emits the trailing `|`, so the mismatch (→ one rescan) is guaranteed,
  never a wrong skip.
- **The wrapped `if` (update.sh:730-731)**: byte-verified backslash
  splice, token-identical, no quoting drift; invisible to the
  string-continuations guard (no quote-adjacent seam).
- **Fix fidelity of the 0.0.40a wave itself**: all seven call sites pass
  the 4th arg; stubs arity-agnostic; the F2 rc-capture works under
  `set -eu` (dash-live-tested by the quality agent); the sed rev-tamper
  hits exactly the rev field (`\|1\|` unique in the 6-field line); the
  stamp-check ordering (3-arg write → dev-owned toggle → 4-arg rewrite
  → dev-user pair → rev tamper) chains correctly.
- **Review bookkeeping**: `bda1c77` added exactly the one allowed
  pointer line to snapshot a; resolution SHAs and index-row claims match
  the commits; the 5→6-field migration costs exactly one extra rescan
