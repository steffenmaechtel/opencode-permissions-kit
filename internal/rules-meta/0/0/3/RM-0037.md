Color escapes are empty when `NO_COLOR` is set or output is piped, so
a tally that counts color bytes reports zeros exactly when output is
machine-consumed (issue #158). The semantic helpers
(`ui_kv_ok/warn/bad`, `ui_have/ui_atten/ui_miss`) render the same
rows and additionally bump `UI_ROWS_OK/WARN/BAD` counters — countable
by call site under every environment. A summary line such as
status.sh's verdict therefore reads the counters, never the byte
stream.

Check: report scripts tally via the ui_kv_* helpers' counters;
nothing greps rendered output for escape sequences.

Source: issue #158 (semantic severity rows).
