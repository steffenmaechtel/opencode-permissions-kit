A real RM number inside an example is textually indistinguishable
from a genuine reference: an IDE plain-text search for that meta then
lists the example among the hits and sends the reader somewhere that
says nothing about the rule. The abstract token `RM-NNNN` carries
the meaning without polluting any search — the record's format
example and decision table already follow it.

Check: searching any real meta's token returns only its meta, its
rule-unit ref, and load-bearing dependencies; examples in docs match
`RM-NNNN`.

Source: maintainer decision 2026-10-15, prompted by a real token
inside the load-bearing rule's own search example.
