The fetch/deploy lists (Makefile `KIT_FILES`, install.sh's fetch
list, the `lib_deploy` manifest) are consumed word-wise: deploy loops
iterate the variable, tests compare word streams — line layout
carries no semantics. One file per line, backslash-continued, is
therefore pure convention, but a load-bearing one for reviews: adding
an entry to a one-per-line list is a one-line diff, while packed
multi-name lines turn every insertion into a multi-line reflow that
hides what actually changed.

Check: the three lists keep one file per line; new entries land as
single-line diffs.

Source: Makefile deploy loop over KIT_FILES.
