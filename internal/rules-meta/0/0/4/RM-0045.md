The audit's unit detector reads col-0 list items — prose paragraphs
are invisible to it, so a rule written as a paragraph gets no meta,
no rationale, no revisit, and nothing ever demands one. Four such
rules sat in conventions.md until 2026-10-17 (severity rows, the
exit-code contract, the file-list layout, the ui_ask shape note).
Rule-bearing prose is therefore rewritten as list items; paragraphs
remain for narrative and lookup content. Making the parser count
paragraphs as units was rejected: it would force metas onto non-rule
prose. Sub-bullets stay unused for the same reason — indented items
are continuation lines to the parser, and a parent would silently
borrow a child's ref.

Check: rule files carry rules as list items; the audit stays the only
unit detector.
