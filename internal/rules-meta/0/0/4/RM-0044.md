An unset-or-empty variable degenerates only when a literal suffix
follows it: `rm -rf "$WORK"/sub` becomes `rm -rf /sub` — a real,
destructive path — while the pure-variable form degenerates to an
empty operand, a verified no-op. The `:?` guard
(`rm -rf "${WORK:?}/sub"`) aborts with the variable name instead. The
check is spelling-proof because every quoting variant degenerates
identically on empty; it scans the unit suites and e2e helper scripts
mechanically, and shipped code holds the same standard by review.

Check: no unguarded var+suffix `rm` in unit suites, e2e helpers, or
shipped scripts.
