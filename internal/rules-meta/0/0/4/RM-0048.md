When real-binary behavior bites, the cheapest closed gap is teaching
the existing double: the unit fake eats stdin under `DDEV_EAT_STDIN=1`,
the e2e fake reads stdin unconditionally — both locked by regression
tests since b14a198. Hermetic and fast, doubles run in every suite
pass, which is what makes them the first line of defense: the
real-binary tier catches what fakes cannot, but only the cheap tier
runs everywhere, every time. A double without its contract lock is a
snapshot — the next refactor of the real binary silently invalidates
it.

Check: the taught behaviors still carry their regression tests in
both tiers.

Source: commit b14a198.
