Sandbox rules enforced only by reviewer memory fail by surprise:
0.0.42e C1 executed a live tree operation on an external review host
before anyone noticed the pattern. The mutation check makes the rule
mechanical — every mutating verb (`rm`, `mkdir`, `chown`, `setfacl`,
…) with a literal absolute-path operand outside the sanctioned
prefixes fails the suite, deterministically, on every host.
Source-to-destination verbs flag only the destination (cp's source
read is not a mutation), `sed` only with `-i`; variables are exempt
because what they hold is review's job, not grep's.

Check: test-sandbox-policy.sh still scans every unit suite for
mutating verbs on out-of-prefix literal paths.

Source: 0.0.42e C1 (live incident on an external review host).
