scripts/advisory-watch.sh — the daily security watch that maintainer
CI runs unattended — skips a malformed feed record with a WARN line
and lets the end gate exit non-zero (`SKIPPED > 0` → `die`): a red
CI run is the only visibility channel an unattended job has, so
failing soft there would silently drop security findings. The
wrapper's hot path (`bin/opencode-as-opencode`) is the opposite
consumer: it probes the installed binary's version for known
advisories on every session start, bounded by `timeout 5`, output
discarded, `|| true` — a failed, hung, or unparseable probe leaves
the version empty, matches nothing, and the session starts anyway
(issue #80: a hung probe once made even `--version` hang). The rule
splits by consumer: unattended automation fails loud, the
interactive session start fails open.

Check: advisory-watch.sh exits non-zero when it skipped records (end
gate); the wrapper's advisory probe skips the check on any probe
failure and the session still starts.

Source: issue #80; scripts/advisory-watch.sh (end gate).
