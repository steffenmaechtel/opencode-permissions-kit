tests/unit/test-security-advisories.sh extracts the shipped screening
guard (`scan_advisory_valid` from scripts/advisory-watch.sh, the same
extract-and-run style this demo family uses) and feeds it real
payload attempts: command substitution inside an advisory id,
search-qualifier smuggling (space + `is:closed in:title`), semicolon
commands, TSV column shifts via a smuggled tab, shell syntax in
ranges. Each attempt must be rejected — an injection defense that
exists only as code is unproven, because refactors quietly break
quoting or allowlists and nothing reddens (agent/test-fidelity.md:
unpinned behavior is unproven behavior). The falsifiable core is the
marker file: the command-substitution payload carries a real `touch`
as text, and if any layer ever executed it, the marker would exist
and the pin fails.

Check: the payload pins still run against the extracted shipped
guard; the marker file stays absent.
