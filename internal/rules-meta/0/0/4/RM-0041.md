An injection defense that exists only as code has no proof it works:
refactors quietly break quoting or allowlists and nothing reddens —
unpinned behavior is unproven behavior (the corpus finding behind
agent/test-fidelity.md). Payload attempts — command substitution in
field values, qualifier smuggling, column shifts — are therefore
unit-tested against the screening code paths. The marker file is the
falsifiable core: the test asserts the payload left no trace, which
fails the moment a defense stops holding.

Check: payload unit tests exist for the screening helpers and assert
the marker file stayed untouched.
