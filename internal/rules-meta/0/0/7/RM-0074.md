Ghost findings are normal, not rare: 0.0.39a retracted two, 0.0.39d
retracted one (a grep that looked unguarded but sat behind a
counting branch). The split keeps both reading contexts on the
code: fresh strong-tier verifiers re-verify each curated finding,
and the main session — the only instance that sees both the
reviewer's claim and the code with the loop's context — audits the
verdicts, re-deriving every MED/HIGH. Without re-verification,
ghosts would flow into the round comments and steer fix waves at
non-existent code.

Check: round comment findings carry verifier verdicts; retracted
items appear in the comment's retraction section, not silently
dropped.
