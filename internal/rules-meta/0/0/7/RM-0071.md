The 0.0.41 chain blurred the four recording roles — dispositions
front-ran into index rows and snapshot prose, and the resolution
became a retroactive reconstruction. The consequence: when the next
review starts from a summary instead of the per-finding ledger, the
why of each disposition is already lost. The PR-native era carries
the same separation on the PR timeline: each round comment's
disposition table is the per-finding ledger with rationale, and any
view over the timeline (GitHub UI filters, markers, the closing
summary) is a summary by construction.

Check: every round comment carries a disposition table covering all
its findings; the closing summary's ledger restates them without
replacing the per-round tables.

Source: internal/records/review-calibration.md, "Recording-role
separation (the 0.0.41 chain)".
