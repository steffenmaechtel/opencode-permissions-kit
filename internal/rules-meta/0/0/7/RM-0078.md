An upstream release on the review day (opencode 1.18.33) changed
login behavior under the suite; without the binary version and host
layout recorded in the snapshot, its results are uninterpretable
afterwards — a later reader cannot distinguish "was broken" from
"ran against a different world". The environment block is what turns
a snapshot into reproducible evidence.

Check: snapshot headers carry opencode binary version and host
layout; anomalous runs attribute to recorded environment drift.
