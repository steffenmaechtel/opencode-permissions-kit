pr-00189 snapshot b reviewed its own fix wave inside the implementing
session: the header carried only the usual "house session" label, and
the same-session fact surfaced in maintainer chat, never in the
snapshot (#189 c C5). The author's context carries its blind spots
into the review of the fix — the rotation exists so a round's author
never reviews their own fixes.

Expected effect (hypothesis, no A/B data yet): better review quality
— the reviewing session reads the fix wave without the implementing
session's justifications loaded, so fix-induced regressions and
commit-vs-claim gaps have a better chance of being named instead of
rationalized. Whether the rotation also raises the raw finding count
is open; quality-per-finding, not count, is the metric.

Check: within a case, consecutive snapshot headers' Reviewer lines
name different sessions; rotation-era wave reviews still catch
fix-induced findings.
