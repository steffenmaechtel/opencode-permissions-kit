The listed set (`files/` incl. sudoers/config templates, tests and
pins, Makefile, workflows, `scripts/`) is exactly what executes or
wires execution — everything else (comments, docs/, CHANGELOG,
bookkeeping) cannot change behavior. The "no trivial carve-out" is
deliberate: the corpus's fix-induced findings arrived at all
severities, so a severity or size exception would reopen the exact
hole the stop rule closed — the chains behind "stop when a round
leaves review-relevant code untouched" (0.0.46a→b, 0.0.47b→c).

Check: the review-relevant list still matches what the kit executes
or wires (new executable surfaces get added here).
