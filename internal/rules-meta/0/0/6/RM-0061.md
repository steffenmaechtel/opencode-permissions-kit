When a round's session ends is a steering decision: the maintainer's
process (internal/process/review.md, "start a fresh session per
review round") owns the pause, because the committed snapshot between
rounds is their visibility window. An agent that chains the next
session itself would consume that window and start reviewing before
the maintainer has read what the last round found.
