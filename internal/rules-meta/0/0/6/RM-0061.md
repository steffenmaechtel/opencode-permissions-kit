The rotation-era pause (a fresh session per round, started by the
maintainer) existed so the maintainer could read what a round found
before its scope was fixed. The PR-native loop replaces the session
boundary with structural pauses: the ask-gates (push, PR creation)
prompt the maintainer, the loop cap forces a handoff, and steering
can freeze scope mid-case (the Pilot 3 precedent). What must NOT
change: a round never consumes the visibility window silently —
completion is reported on the PR timeline, findings and
owed-but-not-run reviews named.

Check: round comments report completion (findings, dispositions,
owed reviews); pushes and PR creation show maintainer approvals in
the session log, never agent self-advances past a gate.

Source: internal/process/review.md; the pilot retrospectives on #278.
