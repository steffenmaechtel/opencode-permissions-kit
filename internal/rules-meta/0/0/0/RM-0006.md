Real answers arrive in mixed case (`Y`, `Yes`, `no`) and real
terminals deliver stray keys; both are ordinary input, not attacks.
The accepted set is exactly what the wrapper's inline `case` matches
after lowercasing — the wrapper cannot source ui.sh, so the set must
stay small enough to inline in every implementation. Input outside
the set must not abort or re-ask: falling back to the default keeps
unattended runs moving without bypassing the deliberate default.

Check: the case arms cover y|yes|n|no (lowercased) in every prompt
implementation; every other answer resolves to the default.
