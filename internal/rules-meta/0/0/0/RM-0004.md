The kit has four prompt implementations that cannot share code:
`ui.sh` (sourced), install.sh's `ui_menu`, uninstall.sh's standalone
`prompt_yn` (no ui.sh), and the wrapper's inline POSIX `case`. Only a
written format keeps them rendering identically. The capital letter is
the single in-band signal of the default — there is no other marker.

Check: grep the four call-site contexts; every shipped yes/no prompt
matches the `[?] <question> [y/N]` shape with the default capitalized.
