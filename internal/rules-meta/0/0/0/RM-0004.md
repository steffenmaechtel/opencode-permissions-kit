The kit has four prompt implementations that cannot share code:
`ui.sh` (sourced), install.sh's `ui_menu`, uninstall.sh's standalone
`prompt_yn` (no ui.sh), and opk's damaged-library fallback. Only a
written format keeps them rendering identically. The capital letter is
the single in-band signal of the default — there is no other marker
(issue #187 B dropped the `[?]` marker that only `prompt_yn` printed;
the wrapper's inline case left the corpus when its container question
was removed in 0.0.21).

Check: grep the call-site contexts; every shipped yes/no prompt
matches the `<question> [y/N]` shape with the default capitalized —
pinned behaviorally in tests/unit/test-ui.sh, test-uninstall.sh and
test-kit-cli.sh (shape + answer semantics).
