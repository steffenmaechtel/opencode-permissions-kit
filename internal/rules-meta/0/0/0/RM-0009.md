One-line report modes (`opk status --short`) run scripts with
`UI_SILENT=1` from start to finish — including paths that can reach a
confirmation. A muted `ui_confirm` would draw nothing and read stdin
anyway: EOF answers empty, which the Enter rule maps to a default the
user never saw. Keeping the question helpers audible is what makes
muting safe to enable globally.

Check: ui.sh mutes print helpers only; `ui_ask`/`ui_confirm`/`ui_menu`
still render under `UI_SILENT=1` (unit-pinned).
