POSIX shells run the right side of a pipeline in a subshell: counters
bumped inside `cmd | while …` vanish when it exits. The severity
counters (`UI_ROWS_OK/WARN/BAD`, issue #158) are read after the loop
by the summary line — fed from a pipeline they report zeros while the
rows printed fine. A temp file plus redirect (`while … done < "$f"`)
runs the loop in the current shell and the tally survives. This is a
language property, not a style preference.

Check: no `| while` loop with `ui_kv_*` calls feeding a summary in
report scripts; such loops read via redirect from a temp file.

Source: issue #158 (semantic severity rows).
