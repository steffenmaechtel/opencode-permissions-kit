Prompts are parsed by more than humans: tests and UX checks assert
the `[?] … [y/N]` shape literally. A second format (`(yes/no)`,
`[yes|no]`, bare `Y/N`) fragments that contract and re-opens the
pre-unification state the archived ux record closed. Choices beyond
yes/no have an existing answer — `ui_menu` with keyed entries — so a
richer prompt never needs a format mutation.

Check: grep `files/` for `(yes/no)`, `[yes|no]`, `Y/N` — no hits;
multi-option prompts use `ui_menu`.
