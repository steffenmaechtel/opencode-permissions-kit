Bugs live in fd variants: a flow correct on EOF stdin can still eat a
pipe's data or hang on a PTY — each variant is a distinct bug
surface, so closed (`<&-`), EOF, pipe-with-data and PTY belong in the
matrix for anything that reads any fd. The same dimension applies to
tool versions: the unreadable-CWD fatal of issue #116 existed only on
git >= 2.55 and was invisible at the distro floor the suite pinned —
hence `E2E_GIT_CHANNEL` resolves the current git-core PPA build at
build time (#118), and the weekly cron rebuild doubles as drift
detection.

Check: stdin-sensitive scenarios run across the stdin variants; the
e2e git channel resolves at build time and the weekly cron still
rebuilds.

Source: issues #116, #118.
