`.sh` tokens exactly the way the guard does — and 0.0.42e C2 exposed
that guard as token-blind (an argument-position suite never
executed). A mechanism reporting on itself shares its blind spots
with the claim it validates; only independent enumeration of
executed commands / on-disk files can witness the guard's failure.

Check: coverage claims in snapshots cite independent enumeration
(on-disk files / executed command list), not the guard's own count.
