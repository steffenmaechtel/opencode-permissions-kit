the house pass had missed, 2 HIGH incl. the executed host-path `rm`
C1 — but the cause was context, not model family. The house
reviewers ran WITH a review skill whose lesson exempted repo-test
`rm` patterns from findings; that lesson was born from an unrelated
UX request — opencode confirms every agent `rm` tool call ("ask"),
and when the maintainer asked for relief from those prompts, the
writing agent over-generalized it into "do NOT report such
patterns". C1 was therefore buried by instruction, not blindness;
the skill-less external pass surfaced it through the executed host
incident, not foresight (pr-00133 review-e.md, C1 + calibration;
skill corrected in nb-ai-skills c5ad310, 2026-10-04). Redundancy
pays through context difference — different training AND freedom
from the reviewing context's biases; 25/26 external findings
survived main-agent verification, and the calibration section makes
the comparison usable rather than anecdotal.
