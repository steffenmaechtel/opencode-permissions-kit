Policy dated 2026-09-29, from provider reality: the strong default
model is expensive per token, Flash is cheap enough to run duplicate
independent reviewers routinely, and higher-reasoning variants were
rejected as timeout-prone (2026-09-27). The compensating control that
makes cheap-tier reviewers safe is the main agent's verification duty
(the "every reviewer-agent finding is re-verified" rule) — depth is
replaced by redundancy, not assumed. The pattern, not the model
names, is the rule (maintainer decision 2026-10-19): the tier pairing
ports to any provider with a fast tier; the house instance is
GLM-5.3 + GLM-5.3-Flash.

Check: snapshot headers record the model per reviewer agent; the
verification marks cover every Flash finding.
