revised 2026-10-01 after the 0.0.39 loop): 0.0.39 j/k validated that
every in-scope diff finding was found within ~8 minutes per agent
with batched greps and targeted reads, no triage deferrals. The
one-follow-up-read rule keeps the ceiling a ceiling — anything
unclear becomes `unverified` for the main agent instead of consuming
the pass. Caveat (maintainer, 2026-10-19): the minutes are guidance,
not enforced limits — subagents frequently run longer; the
checkpoint-timestamps rule collects the evidence that will validate
or recalibrate the numbers.
