A prefix glob (`GHSA-*`) matches any payload behind the prefix — glob
semantics swallow the rest. The negated class `*[!A-Za-z0-9-]*` is
the shape that rejects every foreign character; anchored regexes pin
both ends; `grep -qxF` compares with no metacharacter interpretation
at all. Fields validated this way are the ones that leave as `gh`
argv or query strings, where a crafted value steers the query.
`scripts/advisory-watch.sh` carries the live implementation of all
four shapes.

Check: advisory-watch.sh validation unchanged (negated class,
anchored, vocabulary, `qxF`); new argv/query fields gain a check
before they leave the script.
