Unit suites execute directly on contributor and CI hosts — no
container boundary stands between a test and the real filesystem.
Whatever a suite creates must live where creation is harmless on any
host: its own scratch and the FHS temp prefixes present on every
Linux (`/tmp`, `/var/tmp`). The policy suite enforces that prefix
allowlist on mutating verbs, so an out-of-prefix write fails review
instead of luck.

Check: `test-sandbox-policy.sh` mutation check still fails
out-of-prefix literal destinations.
