Untrusted values reach the scripts as shell variables, and POSIX sh
gives every unquoted expansion word splitting and globbing — the two
classic injection surfaces. `eval` and `sh -c` with interpolated
values execute data as structure outright. ShellCheck flags each of
these shapes (SC2086 class, eval class), and `make lint` is the
repo-wide gate; the rule keeps shipped code on the passing side of
that gate.

Check: `make lint` stays in CI and passes; no `eval`/`sh -c` with
interpolated external values in `files/`.
