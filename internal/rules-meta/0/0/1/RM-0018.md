is ambiguous the moment a second case exists. GitHub allocates PR
numbers when the birth-PR opens, before parallel features merge —
numbers cannot collide between concurrent cases. Snapshot letter plus
finding ID inside the PR key (`(#176 a W1)`) restores global
uniqueness while staying grep-able as one literal string.
