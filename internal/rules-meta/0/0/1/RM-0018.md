The PR-native process (operational since 2026-10-26, Pilot 1) runs a
case entirely in its birth-PR's timeline: the round comments carry
the findings, the dispositions and the opk-review markers. A citation
`(#291 a S1)` therefore has exactly one durable resolution target —
the PR timeline — and GitHub allocates PR numbers at creation, so
parallel features can never collide. Fix commits qualifying their
citations the same way is what makes a commit's claim traceable to
the round that produced the finding.
