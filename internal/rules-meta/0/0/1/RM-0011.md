In `printf "$EXT"` the data becomes the format string: `%` and `\`
sequences in the value are interpreted, mangling output or erroring —
POSIX printf behavior, independent of quoting. A fixed format with the
value as an argument (`printf '%s' "$EXT"`) cannot reinterpret the
value. External data full of literal `%` and backslashes (issue
bodies, feed fields) is normal input here, not a hostile edge case.

Check: no printf with a variable format string in `files/` (grep for
`printf "$`).
