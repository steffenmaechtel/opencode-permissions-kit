A fixed host path in a cleanup (`rm -rf /some/path ...`) deletes
whatever lives there on whichever host runs the suite — the 0.0.42e C1
incident executed exactly that on an external review host. Teardown
is the dangerous spot: it runs after the asserts, so a mid-suite
failure neither stops it nor has checked what it targets. The ratchet
check therefore flags real-tree literals in fixture strings as much
as in commands.

Check: the real-tree ratchet (check 2) still fails literals under
`/var/www/vhosts`, `/home`, `/srv`, `/etc` in unit suites.

Source: 0.0.42e C1 (live incident on an external review host).
