argv is a steering surface: a body starting with `--` is parsed as a
flag, and the kernel imposes ARG_MAX on the whole command line.
Upstream `gh` offers `--body-file` for exactly this reason — long
free text belongs in a file handle, not an argument vector. Moving
issue bodies through temp files keeps untrusted prose from ever
reaching an argument parser.

Check: issue/message bodies flow via `--body-file` temp files; no
external free text passed as positional or flag arguments.
