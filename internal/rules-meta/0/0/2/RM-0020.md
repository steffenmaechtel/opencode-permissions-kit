The repo's rules accumulated across review waves 0.0.38–0.0.49 and
maintainer directives; several had gone stale and surfaced only by
accident — that is this system's origin. A reviewing agent cannot
tell a still-binding rule from an obsolete one unless the rule records
what it responds to. External files, because rule texts are always-on
reading: inline rationale would tax every agent session, not just
revisits.

Check: for each rule, a revisit can decide keep/update/retire by
testing the stated fact.
