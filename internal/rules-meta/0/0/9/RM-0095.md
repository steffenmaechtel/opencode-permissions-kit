Tables in rule files carry lookup and reference material — the
review-types table, the decisions table — rows are consulted, not
obeyed. Treating each row as a rule unit would multiply metas
without revisit value: nothing about a lookup row rots in the way a
rationale-bearing rule does. The audit implements the split
mechanically (table lines never open a unit, rules-audit.sh pass 1).
Validated across the pilot: every equipped file from 2026-10-14 to
2026-10-19 operated with tables un-unitized and no row-rot ever
surfaced.

Check: the audit still treats table lines as non-units; rule files
keep tables as lookup without per-row refs.

Source: pilot default, validated by Phases 0–3.
