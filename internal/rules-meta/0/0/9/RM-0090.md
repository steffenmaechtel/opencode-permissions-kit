The checkpoint/digest/verdict file is the durable artifact — written
to session scratch, the input later stages (curator, verifiers, the
round comment) actually read; chat is ephemeral session output that
scrolls away. A subagent's final message lands in the parent
session's context — that IS the bloat path (Pilot 2 round b: 3/3
reviewers returned full content, the main session salvaged files by
hand and the round's context inflated; after the contract was
spec'd, 0 violations in 14 launches across P3 and Case A). The file
is the transport, the response only the pointer.

Check: file-producing subagents return exactly one status line plus
path(s); round comments are composed from files, never from
transcribed responses; violations are disclosed in run provenance.

Source: the subagent output contract spec (adopted Pilot 3,
#278 retrospective); concept file practice since the 0.0.39 loop.
