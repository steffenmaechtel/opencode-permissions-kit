milestone is expected to arrive through the ddev and opencode
communities (Discord, issues, blog posts — the release-handling
adoption roadmap), and installed kits report back through GitHub
issues, where pasted terminal output must stay searchable and quotable
for readers who do not speak German. The maintainer's own working
language is German, so untranslated prose would drift in by default —
the rule exists because the drift direction is known, not
hypothetical.
