Metas are read standalone at revisit — one file, no INDEX open — so
an RM number inside a rationale forces a lookup hop the reading mode
does not have. Full-text search for an RM number must return
references and rule units, not prose mentions: the same
indistinguishability argument that bans real meta numbers inside
examples (the abstract-token rule in the same section). Born
2026-10-19 when the review-concept batch's rationales carried
RM-number cross-refs; the maintainer ordered rule text instead and a
sweep fixed five metas (one pre-dating the batch).

Check: a grep for RM-number cross-references over the meta tree
returns none inside rationale bodies.

Source: maintainer decision 2026-10-19 (first review of the
review-concept batch).
