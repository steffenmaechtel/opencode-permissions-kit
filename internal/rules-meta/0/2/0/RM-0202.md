The host-stamp rule in this section ("Parallel reviewer agents") names
exactly two stamps — fan-out start and end — and the round-comment
contract's mechanical-fields rule ("The round comment contract") covers
marker counts and posting stamps; every OTHER window a
run-provenance section names
(reviewer returns, verification spans) had no stamping duty, so
composition-time estimation slipped through as prose. PR #726 round a
(2026-11-21): the posted provenance carried reviewer-return and
verification windows as elapsed-time estimates; round b's fan-out host
clock read earlier than the estimated windows, falsifying all of them,
and the correction had to ride round b's provenance comment,
append-only. Estimates composed after the fact are indistinguishable
from measurements in the posted text — which is exactly why they must
not appear.

Check: run-provenance windows in recent round comments trace to host
`date -u` records in the case scratch, and unmeasured windows say so.
