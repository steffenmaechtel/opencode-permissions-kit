The re-quoted-figures rule above (this section, "Verification duty")
governs tokens riding a finding's
prose; a figure the session generates itself — born in its own probe
output — has the same discipline need with a different anchor, and the
rule's letter read as not covering it. PR #724 round a C1
(2026-11-21): a corpus figure spoken as an eyeballed line count of
probe output landed in the record, the PR body and a commit message;
after the commit, a deterministic wc/awk recount of the same probe
gave a smaller figure on both the unit and the filter (the eyeballed
number reproduced only under a different unit and a retired-inclusive
filter — the round re-derived it two independent ways). An eyeballed
count is a draft, not a measurement; the probe output IS the primary
source and transcription from it is by command.

Check: a record, commit message or PR body citing a session-generated
figure names the counting command (or pastes its output) — a figure
with no derivation behind it is the ungated fact returning.

Source: issue #725 item 1 (PR #724 round a C1).
