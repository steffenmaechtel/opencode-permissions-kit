The intake keeps issues open for weeks by design, so the pilot's
nothing-rots promise (every issue dispositioned) needs a disposition
for topics that never recur (issue #755). Three months without a new
confirming session is the maintainer's starting window (chat
2026-11-22). Closing as not planned keeps the issue searchable for a
later session that hits the topic again — the producer contract
reopens a match closed this way.

Check: The monthly sweep lists what it closed; an unpromoted issue
older than the window without a sweep entry is a missed disposition.

Source: issue #755.
