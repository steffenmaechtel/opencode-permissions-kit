The meta-analysis of the review corpus 0.0.38–0.0.46 found the same
error classes recurring with every new feature: `silent-failure`
appeared in all nine version groups, snapshots cross-reference earlier
findings as a "class" 45 times, and 20 % of all findings were
introduced by the project's own fix waves. Classes collapsed to zero
only after an enforced process step existed — naming a class alone
never stopped it. The checklist is that step, and "declaring the work
done" is exactly the claim the corpus shows to be wrong when the
checklist was skipped.

Check: feature waves run the checklist before the commit and again
before the done claim; reviews-meta runs track class counts toward
zero.
