Users meet the kit only through the docs and the streamed scripts —
there is no support channel that corrects a stale page, and installed
kits update silently via `opk update`. A behavior change merged
without its docs page therefore ships wrong instructions to every
reader until an issue arrives describing behavior that no longer
exists; issue reports come from installed kits on other machines, so
the mismatch surfaces late and second-hand.

Check: PRs that change user-facing behavior touch the matching
`docs/` page in the same PR.

Source: CONTRIBUTING.md, Documentation; docs/README.md (page
structure).
