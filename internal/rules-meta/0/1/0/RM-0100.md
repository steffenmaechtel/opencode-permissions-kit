Users meet the kit only through the docs and the streamed scripts —
there is no support channel that corrects a stale page. `opk update`
deploys changed script behavior without any note to the user, and
the docs are not part of what it deploys: an updated kit keeps
instructing its user with the old page, so the drift is not visible
from the machine itself. A behavior change merged without its docs
page therefore ships wrong instructions until an issue arrives
describing behavior that no longer exists — from an installed kit on
another machine, late and second-hand.

Check: PRs that change user-facing behavior touch the matching
`docs/` page in the same PR.

Source: CONTRIBUTING.md, Documentation; docs/README.md (page
structure).
