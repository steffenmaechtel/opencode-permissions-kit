The fixes-need-a-go rule covered only fix waves; nothing said who
owns the owed wave review, and the pr-00211 agent fired it itself
twice. The commission now defines the cadence per variant:
maintainer-gated commissions fire every round on the maintainer's
go; autonomous commissions (variant c) chain rounds back to back
inside the loop cap — the pilot series ran both shapes — but pushes
and PR creation are the agent's job in every shape (AGENTS.md Rules (the never-commit-on-master rule):
approval validity needs the agent as author and last pusher; the
opencode permission prompts stay the runtime gate), and round
completion is always reported with owed-but-not-run reviews named.

Expected effect: round boundaries are explicit, gated decisions
where gates exist and reported events where they do not; the agent
never self-advances past a gate.

Check: pushes and PR creation run as the agent behind opencode
permission prompts visible in the session log (PR author and last
pusher are the agent — approval validity); round comments report
completion including owed reviews.

Source: issue #213 item 2 (pr-00211 post-mortem); the pilot
retrospectives on #278.
