The session-rotation intro ("Inside a review session, the reviewer
mechanics below apply unchanged") was read in pr-00211 as permitting
in-session review passes to satisfy the rotation. The sentence
governs the mechanics of a pass, not which session may review:
subagent freshness is required WITHIN the reviewing session, but the
session that authored a round's fixes still never reviews them.
Single-session chains are a USER decision per case, recorded in
provenance — never an agent's self-declared mode.

Expected effect: rotation questions resolve to the session boundary;
agents stop reading the mechanics sentence as a rotation exemption.

Check: consecutive rounds' snapshot Reviewer lines name different
sessions unless the USER sanctioned single-session mode for the case
(visible in provenance).

Source: issue #213 item 6 (pr-00211 post-mortem); decision from the
issue-213/214 docs wave: the session stays the measure.
