A reflection issue narrates what a session believed happened — its
mechanism claims are evidence about the incident, not verified truth.
The first live case: #578 §3 said sh -n passes on the
apostrophe-mangled worker; the wave wrote that mechanism into the
conventions rule and its meta unprobed, and pr-00586 round a's
probes showed it conditional — an unbalanced apostrophe count fails
sh -n on the outer file outright, while a balanced pair concatenates
into a worker sh -n accepts that silently drops every command behind
the comment. The verification duty already demanded probes before
CONFIRMED verdicts; this rule extends the same discipline to writing
the rule text itself.
Check: a wave adding mechanism prose to agent/ rule files shows its
scratch probe (transcript or log path) in the PR body or a linked
comment.
Source: issue #588 §2; issue #578 §3.
