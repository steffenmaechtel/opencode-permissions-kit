The release gate is the repo's heaviest review: every fix wave on it
ships to user machines via the stable mirror, and in practice those
fix waves touch files/** — pr-00568's wave a did in 6 of 7 commits
(config.sh, ddev-handover.sh, ddev-migrate.sh, update-core.sh,
install-core.sh, tui/*.tsx, py/tui-register.py), 8 of the PR's 22
changed files overall. A VERSION-only diff still selects the light
non-shipped posture under the mechanical track rule —
deliberately-not-done LOW/INFO findings, light staffing — exactly
wrong for a release gate, so the release-gate commission itself
justifies shipped-track staffing from creation.
Check: the newest release PR's body carries the shipped marker from
creation, not a non-shipped line corrected later.
