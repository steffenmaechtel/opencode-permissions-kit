Pilot 3's measurable signature of a self-feeding loop: the
a S1 → b S1 → c S1 → d D1 chain was almost entirely fix-induced —
each round legitimately found real defects in the guard the previous
round built, while the inventory itself was clean after round a.
Predominantly fix-induced findings mean the built surface is still
growing; the loop status must name that state before the maintainer
has to (the #278 Pilot 3 retrospective folded this proposal into
this rewrite).

Check: loop statuses classify each round's findings by provenance
share; building rounds say so explicitly.
