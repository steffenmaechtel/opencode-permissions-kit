GitHub reports a check's state as "green" only per completed run;
while a run is in progress its eventual result exists nowhere on the
tracker, and notification mails surface only the round comment's
headline status line. A closing summary that claimed "CI green on
both pushes" while push 2's run was still in progress (PR #531,
2026-11-15) was true of push 1 only and needed a correction comment
when the `e2e-2x-git-latest` lane failed on the finished run.

Check: a round comment or closing summary whose CI line names a check
result quotes a completed run (gh run list/view state succeeded);
in-progress runs are labeled as such in the line.

Source: issue #534 §2 (end-of-session reflection over PR #531).
