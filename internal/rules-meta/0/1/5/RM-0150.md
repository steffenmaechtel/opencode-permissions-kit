dash's `if !` negation clobbers `$?`: PR #520 round a A1 found a death
diagnostic that always said rc=0 because it read `$?` inside the
negated branch — every sibling guard in the same wave used
`cmd || var=$?` correctly. Tool rc semantics differ besides: grep rc 1
is "no match" (normal), rc ≥ 2 is death; awk rc ≠ 0 is death — one
capture idiom covers both facts.

Check: plant a failing producer behind `if !` and print `$?` in the
branch under dash; it shows the negation's residue, not the rc.

Source: issue #523 §2 (#520 a A1).
