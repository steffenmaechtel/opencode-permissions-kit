All fence-aware tooling in this repo is column-0-anchored (the
rules-audit unit parser's fence regex, the line-length ratchet's
fence skipping) — an indented fence inside a rule bullet is invisible
to every consumer, so structural damage there has no gate: #526's C4
fix deleted a template fence's opening line in review-concept.md and
every suite stayed green; the maintainer's read caught it. Round a B2
had recorded the parser blindness as an INFO footnote without
connecting it to the missing well-formedness guard.

Check: delete an indented fence's opening line in an agent/ rule file
and run the full suite — nothing reds.
