The first draft of the standing-prose roster rule's meta (commit
d1326037) quoted "the whole population of 14" as its unscoped-count
evidence — a composite matching no source: docs-loop's pre-fix
text carried no count, and the real "exactly 14 issues carry
`from-reflection`" lived in PR #555's body (live state, a different
rule's class). PR #557 round a (finding a Q1) caught it; ab48d581
fixed the citation. The machinery parity-checks the frontmatter needle
against the rule text, but nothing checked quoted strings inside meta
bodies — the one document class whose product is provenance.

Check: every quotation-marked string in a new meta's body greps
true in its named source (file, PR body, or named git commit)
before posting.

Source: issue #558 §1 (PR #557 round a Q1, fix ab48d581).
