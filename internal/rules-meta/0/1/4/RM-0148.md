shape that discriminates is capturing `( producer <dying input> )
2>&1 >/dev/null` and asserting rc AND message. PR #496 round b D3
found a death arm that pinned the guard message only — a
message-preserving rc regression (`return 0` at the producer, or
dropping the call site's `|| exit 1`) kept the arm green while batch
deaths went vacuously green again; the b-wave fix (a6c071d0) derived
the rc assertion from the same executed death, sabotage cycle 5. The
redirection-order hazard — swapping `2>&1` and `>/dev/null` makes the
arm vacuous — is recorded from the #519-wave session narrative (issue
#523 §1; no round finding carries it).

Check: plant a message-preserving rc regression (producer `return 0`
on the death path) and swap the redirection order in any death arm;
the arm must go red on both.
