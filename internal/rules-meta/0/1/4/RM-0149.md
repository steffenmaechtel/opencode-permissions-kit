An empty scan set is not evidence of cleanliness: a detector handed
zero files returns zero findings and looks green precisely when its
input died upstream. The trap-analyzer adoption wave (#498/#516)
shipped the reference semantics — `trap_detect`'s "no files given"
rc 1.

Check: run any sweep detector with an empty file list; it must fail
loud, not report clean.
