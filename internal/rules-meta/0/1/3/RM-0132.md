Context data from the same pilot: implementer-session reviews
compounded to 303k context over six cases while fresh single-PR
review sessions stayed flat at 83–110k. A flash axis costs the same
wall-clock time as the session reviewing directly (subagents run in
parallel; main waits either way), so the uniform
review-is-always-a-subagent rule needs no exception in the no-solo
rule. PR #320 ran the loop with a main-direct round (a reviewers:0
marker) — kept as precedent for the LOOP shape, not the review-pass
shape.

Check: new-session markers carry mode new-session-review and
reviewers ≥ 1 in every round; the record shows one review session
per PR.
