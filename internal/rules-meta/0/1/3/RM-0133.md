re-review LOW/INFO findings on non-shipped diffs; under this policy
the same batch models at ~9 rounds and ~1h–1h15 active review with
both MED/HIGH chains fully reviewed. A LOW fix buys a full extra

wrong spend on non-shipped code. The pin-completion exception
(≤ ~3 lines) exists because #330 A2 stranded a 2-line pin completion

exception moves the FIX into the round, never the re-review: the pin
diff is a code touch and owes the low-tier (one-axis) re-review

invited a stop-rule bypass).
