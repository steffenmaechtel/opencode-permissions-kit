When one literal line shape must stay byte-identical across several
kinds of site — docs blocks, a shipped script, unit pins, a fixture —
the pins can only compare fragments, so they guard partial drift by
design; a full shape change is a coordinated move across every site,
and a wave that changes one site at a time reds (or worse, greens)
piecemeal. The pr-00600 echo-hash install line spread across README,
docs/getting-started.md, the landing page (.github/pages/index.md),
scripts/release-sums.sh and the pins and fixtures of its suites; the
wave recorded the enumerating grep so the next shape change starts
from the site list instead of rediscovering it (round a A8, round d
D1).

Check: the wave that changed the echo-hash line last cites the grep
enumerating its sites.
