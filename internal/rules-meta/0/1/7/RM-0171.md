Users paste docs blocks into an interactive shell, which runs no
set -e: sequential plain lines execute one after the next regardless
of each line's rc, so a check line that prints its error still lets
the following execution line run. The verified-install 3-liner in
README.md and docs/getting-started.md shipped as three plain lines
after three review axes had verified the commands executable as
printed; the maintainer caught that a failed sha256sum check did not
stop the sudo install line (fixed in 0f68f4d1 as one compound
command with a trailing && per line, verified for block paste and
line-by-line paste in round d).
Check: every docs block whose prose promises gating greps as one
compound command (a trailing && on every line but the last).
Source: issue #604.
