tests/e2e/lib.sh prints its FAIL and WARNING lines as console
progress lines — plain echo on stdout — unlike shipped runners,
whose diagnostics the conventions route to stderr. A failure-arm
drive that asserts such a line therefore captures stdout and greps
there; the #601 chmod-failure drive in PR #628 first captured stderr
only and saw an empty file with rc and file state already green
(issue #631).
Check: grep the e2e lib for FAIL emissions shows echo with no stderr
redirect; a drive asserting the line greps a stdout capture.
Source: issue #631.
