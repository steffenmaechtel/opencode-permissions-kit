Wave records — PR bodies, fix-wave comments, shipped comments —
carry exhaustive claims over code state, and code state drifts under
them: PR #680's loop refuted every count and every "only/every +
narrow scope" phrasing it met, each at a finer scope than the last
(the two-sites claim fell to a third site; the fixed-path claim fell
to non-namespaced sites; the only-point claim fell inside its own
function, and each reword fell again) — only the enumeration by
OPEN CLASS over the code's taxonomy survived every round ("every
probe of the opencode binary in the update path — fresh candidate,
freshly deployed, old deployed (same trust class)"). A count is a
snapshot the next round's finer grep refutes; a class enumeration or
a cited grep is checkable.

Check: every exhaustive claim in a wave record names its class
taxonomy or the grep that derives it; review flags bare counts and
"only/every + scope" phrasings and asks for the derivation.

Source: issue #683 item 2 (PR #680: round a findings B2 and B3,
round b finding B2, round c findings C1 and C2).
