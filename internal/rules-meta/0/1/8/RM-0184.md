The round diff range keys both the review material and the tier's
line classification, and master on this repo moves mid-session as a
norm: the maintainer merges parallel waves, and sessions run as
parallel git worktrees that share refs/heads — a master pull in one
worktree advances the ref in the other without any pull there
(scratch-verified 2026-11-18, the wave over issue #649). A two-dot
`master..HEAD` diff compares endpoints: it silently includes
reverting every master advance since the branch point. PR #642's
round a pre-flight read a 16-file +265/−100 endpoint diff including
deletions in files the wave never touched, over a one-commit wave;
the log-vs-diff divergence exposed it and the merge-base range
showed the wave's own change only.
Check: the round diff range is the merge-base..HEAD of the session's
branch, re-derived at staging time — scratch-verified that a master
advance after the branch point produces a phantom deletion in the
two-dot stat and none in the merge-base stat.
Source: issue #649.
