(`0.0.42e C1`) inline; a bare `#37` would be ambiguous to grep, and
this repo works by grep. Numbers are never recycled because git
history and old review documents keep citing RM numbers — a recycled
number would silently point those citations at the wrong rationale.

positional numbering would break on every move. 5 digits match
PR-number width and cover the full rollout without re-padding.
