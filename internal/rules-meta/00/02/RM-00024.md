A single folder holding dozens of metas becomes a wall in IDE trees;
the maintainer wants small folders (~10-20 files each). The two-level
scheme consumes four of the five ID digits — a leaf holds exactly the
ten IDs sharing the first four — and every level is computable from
the token alone: no bookkeeping, no semantic mapping, and a rule
moving between files can never affect where its meta lives. Level 1
stays a single `00/` until ID 10,000, so today the scheme behaves
like a flat 4-digit shard with a constant prefix, and beyond that it
caps the top level without any migration. Migrated while the corpus
was young (a pure `git mv`) because later consumers — index, audit,
bookmarks — would have pinned the old paths.

Check: every meta file sits in `NN/NN/` matching its first four ID
digits; no leaf folder exceeds 10 files.

Source: maintainer decision 2026-10-15 (NN/NN two-level scheme,
after the digit-math walkthrough).
