The honest case against the index: it is derived state — "which
rules exist" is answered by the rule files themselves, and "what is
due" is a report's job. The honest case for it: at 100+ metas a
generated table of contents gives the folder a human entry point that
grep cannot offer, because browsing needs a place to start when you
do not yet know what to search for. We keep it for now and are
explicitly unsure; the alternative on record is dropping the
committed file for an on-demand `make rules-report`.

Check: the index is regenerated by every audit run — or has been
replaced by the report; the first revisits decide with evidence.
