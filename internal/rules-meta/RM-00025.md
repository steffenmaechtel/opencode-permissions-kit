With 100+ flat files, manual navigation breaks down; the INDEX is the
navigation layer, grouped by source file and section (same pattern as
the generated review `INDEX.md`). It is regenerated on every audit
run because a manually refreshed index goes stale exactly when it is
needed — and CI runs the audit anyway, so regeneration is free and
the index cannot lie.

Check: after an audit run, INDEX matches the metas on disk.
