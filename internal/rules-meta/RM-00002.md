Prompts gate steps that change the system (uninstall, user removal,
provisioning) — usually under sudo. Empty input accepts the default.
So the default is what a hasty Enter runs, and it must be the safe
answer: `n`. Skipping is recoverable (re-run); confirming is not.

Check: grep `ui_confirm` / `prompt_yn` in `files/` — destructive
prompts default `n`, `y` only where "no" is riskier.
